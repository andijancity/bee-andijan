================================================
BEELINE ANDIJAN GIS NETWORK HUB - HOSTING GUIDE
================================================

ИНСТРУКЦИЯ ПО УСТАНОВКЕ НА ХОСТИНГ:

1. Распакуйте все файлы из этого ZIP архива в корневую папку вашего хостинга (обычно public_html, www или htdocs).
2. Структура файлов на сервере:
   ├── index.html
   ├── style.css
   ├── app.js
   └── data.json
3. Перейдите по адресу вашего домена в браузере (например, https://your-domain.uz).

Сайт полностью автономен, использует бесплатные тайлы Esri (без 403 ошибок) и готовые API OSRM для маршрутизации.
